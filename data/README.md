# data

| 폴더 | 내용 | 커밋 |
|---|---|---|
| `raw/` | AI Hub「법률/규정 텍스트 분석 데이터」 원본 | ❌ (Lab 서버 공유 디렉터리에만 보관) |
| `processed/` | 분할·정제된 학습 데이터 | ❌ |
| `gold/` | 관계 정답셋(보험 약관 조항 100~150개)과 주석 가이드 | ✅ |
| `demo/` | 데모용 공개 약관 PDF·DOCX | ✅ |

- AI Hub 데이터는 재배포 조건을 이용정책에서 확인하기 전까지 저장소에 올리지 않는다.
- 관계 정답셋은 LLM 출력을 보지 않고 두 사람이 독립 주석한 뒤 협의해 확정한다 (SPEC 참고).
