# 메인 딥러닝 실험은 AI Hub 약관 유불리 라벨로, 관계 추출은 학습하지 않는다

불리 판정은 법적 판단이라 팀이 직접 붙인 라벨로는 신뢰를 얻기 어렵고, 약 5주(37일) 안에 주석할 수 있는 양(수백 건)으로는 모델 비교가 의미 없다. 그래서 판단 근거·관련 법령이 붙은 AI Hub「법률/규정 텍스트 분석 데이터」의 약관 약 1만 건으로 유리/불리 이진 분류 + 관련 조문(약관법 제6~14조) 다중 라벨 분류를 메인 실험으로 삼는다 (E0 TF-IDF+SVM → E1 KLUE-RoBERTa-base → E2 large → E3 메타정보 추가). 관계 라벨이 있는 계약·약관 데이터는 없으므로 관계 추출은 학습하지 않고, 직접 만든 정답 100~150개 조항으로 평가만 한다.

## Consequences

- 데이터의 '불리한 조항 유형' 필드는 값이 2개(신의성실 위반 / 개별금지 조항 위반)뿐이라 분류 대상으로 쓰지 않고, 관련 법령 필드에서 조문 라벨을 만든다. 한 조항에 여러 조문이 적힐 수 있어 다중 라벨로 다룬다(v2 개정).
- 공개 라벨 필드에는 출처 약관 식별자가 없어 같은 약관의 조항이 여러 분할에 섞일 수 있다. 1주 차에 출처 정보 유무를 확인해, 있으면 그룹 분할을 쓰고 없으면 근사 중복을 제거한다.
- AI Hub가 보고한 유불리 F1이 0.91이라 이진 분류만으로는 개선 폭이 작을 수 있다. 관련 조문 분류가 모델 간 차이를 보여주는 주 과제다.
- 데이터 라벨이 고객 관점이므로 판정도 고객 관점 하나뿐이다 (ADR 0004 참고).
