## 종료 결정

- 결정: r3를 하지 않고 2회차로 교차 검증을 마친다 (2026-11-08, 고용민).
- 이유: r2 지적은 대부분 r1 수정에서 이어진 문제였고, 회차를 늘리면 모델끼리 서로의 수정을 다시 고치는 공방이 되어 얻는 것이 줄어든다고 판단했다. Harness §3 ①의 횟수는 상한이며, 최종 결정은 사람이 하고 이유를 남긴다.
- 남는 위험: r2 반영분은 다른 계열 모델이 다시 보지 않았다. 대신 작성자 검사(하위 티켓 ID 일치, 선행 ID 존재, 순환 선행 없음, 부모 행 변경 없음, 금지 표현 없음, 링크)를 실행해 모두 통과했다. 구현 중 계획 오류가 드러나면 사람이 정해 `03-plan.md`부터 고친다.
- 다시 검증이 필요해지면 아래 프롬프트를 쓴다.
