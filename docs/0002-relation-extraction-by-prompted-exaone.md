# 관계 그래프는 EXAONE 4.5 33B 프롬프트 추출 + 원문 문자열 검증으로 만든다

관계 학습 데이터가 없고 데모를 Lab RTX 5090에서 돌리므로, 외부 API 대신 로컬 오픈 LLM에 지시문·조항 원문·출력 형식을 주고 JSON으로 관계를 받는다. 모든 관계에는 원문 문장을 그대로 복사하게 하고, 그 문장이 원문에 실제로 없으면 버린다. 모델은 EXAONE 4.5 33B(AWQ 4비트, `enable_thinking=False`)로 고정하고, 다른 오픈 LLM과의 비교 실험은 하지 않는다.

## Considered Options

- 외부 API(Claude/GPT): 로컬 서버만으로 시연한다는 방침과 맞지 않아 제외.
- 규칙 기반, 직접 주석한 데이터로 관계 추출 모델 파인튜닝: 각각 품질과 일정 문제로 제외.
- EXAONE 3.5 7.8B Instruct(`LGAI-EXAONE/EXAONE-3.5-7.8B-Instruct`, bf16): 대체안으로 남겨 둔다. 1주 차에 동시 요청으로 시험해, 데모 약관 1개 처리가 3분을 넘거나 JSON 오류가 잦으면 이 모델로 바꾼다. 3.5에는 추론 모드 옵션이 없으므로 LLM 호출부는 모델별 옵션을 감싼다.

## Consequences

- 공식 서빙 예시(`LGAI-EXAONE/EXAONE-4.5-33B-AWQ`)는 GPU 2장·256K 컨텍스트 기준이다. 단일 RTX 5090에서는 세 가지 설정이 필요하다.
  - 컨텍스트 상한을 조항 단위 작업에 맞게 줄인다.
  - 이미지 입력을 0으로 막는다(비전 인코더를 쓰지 않음).
  - GPU 메모리 사용률 상한으로 RoBERTa 추론 몫을 남긴다.
- RoBERTa 학습과 EXAONE 서빙을 같은 GPU에 동시에 올리지 않는다.
- 모델이 `\boxed{}` 답변 형식을 선호하므로, 지시문에 JSON 형식을 강제하고 응답 처리에서 형식 이탈을 걸러낸다.
