# 🔴/🟡/표시 없음 기준선은 사람이 정하지 않고 클래스 조건부 Conformal Prediction으로 계산한다

조항 표시 3단계(불리 조항 / 확인 필요 / 표시 없음)에는 공식 기준이 없다. 팀이나 이용자가 임의로 숫자를 정하면 객관성이 없다. 그래서 이진 모델 출력에 **클래스 조건부(Mondrian) split conformal prediction**(보장 수준 90%)을 적용한다. 유리·불리 각 클래스의 보정 데이터로 기준값을 따로 구한다. 예측 집합 매핑은 다음과 같다.

- {불리} → 🔴
- {유리, 불리} 또는 빈 집합 → 🟡
- {유리} → 표시 없음

이렇게 하면 실제 불리 조항의 90% 이상이 🔴 또는 🟡로 표시된다. 사람이 고르는 값은 보장 수준 하나뿐이고, 기준선 자체는 보정 데이터가 정한다.

## Considered Options

- 일반(marginal) split conformal: 클래스 비율이 기울면 소수 클래스의 포함률이 90%에 못 미칠 수 있다. "불리 조항을 놓치지 않는다"는 약속을 클래스별로 보장하지 못해 제외했다.
- 목표 지표 방식(🔴 정밀도 90%, 🔴+🟡 재현율 95%): 비교 자료로 수치만 함께 보고한다.

## Consequences

- 이진 분류에서 온도 스케일링은 클래스 확률의 순서를 바꾸지 않아 예측 집합에 영향이 없다. 그래서 온도 스케일링은 화면에 보이는 불리 확률과 보정 오차 개선에만 쓴다(v1의 "보정 후 Conformal" 서술을 바로잡음).
- Conformal 보정용 분할(전체의 10%)을 모델 선택용 검증 분할과 따로 둔다.
- 모델이 매우 정확하면 기준값이 높아져, 두 클래스 모두 기준에 못 미치는 빈 집합이 생길 수 있다. 이 경우 🟡로 처리하고 비율을 보고한다.
