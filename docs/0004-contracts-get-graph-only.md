# 개별 계약서에는 불리 판정을 하지 않고 관계 그래프만 보여준다

약관법은 여러 상대방과 계약하기 위해 미리 마련한 약관에만 적용되고(제2조), 개별 합의는 약관보다 우선한다(제4조). 학습 데이터도 약관뿐이다. 그래서 개별 계약서에 약관법 관련 조문과 불리 판정을 붙이면 법적으로 틀린 설명이 된다. 계약서도 업로드할 수 있지만 조항 구조와 관계 그래프만 보여준다(B-lite). 문서 유형은 이용자가 업로드 때 직접 고르고 규칙 기반 추정은 기본값 제안에만 쓴다. 자동 판별기와 계약서 정답셋은 만들지 않는다.

## Consequences

- 계약서 그래프의 당사자 명칭은 문서에 적힌 대로(갑/을 등) 표시하고, 검토 관점(고객/사업자)은 약관에만 적용한다.
- 사업자 관점은 별도 판정이 아니라 같은 🔴 판정을 "무효·시정 위험 조항"으로 읽는 화면 문구다.
